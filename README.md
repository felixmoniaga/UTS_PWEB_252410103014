## WarungSuki

Aplikasi web pengelolaan daftar menu makanan dan minuman, dibuat dengan Laravel (MVC dan Blade) untuk UTS Pemrograman Web 2026.

Nama: Felix Jericho Moniaga
NIM: 252410103014

## Fitur
- Login dengan username, lalu username dikirim ke Dashboard dan Profile
- Halaman Pengelolaan menampilkan daftar menu dari array di Controller
- Layout, navbar, dan footer memakai Blade
